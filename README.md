# MarkPro — Marksheet Generator Website

This folder contains a polished frontend demonstration for the **C-language Marksheet Generator project**.

## Files
- `index.html` — page structure
- `style.css` — responsive UI and theme
- `script.js` — marksheet calculations and browser interactions

## Features
- Student details
- Five subjects
- Marks validation (0–100)
- Total, percentage and average
- Grade and PASS/FAIL
- Subject performance
- Best and lowest subject
- Performance progress bar
- Demo data
- Dark mode
- Print / Save as PDF
- Copy result summary
- Local browser record storage
- Saved-record list with delete
- Responsive design

## Important
This website is a **frontend demonstration/interface**. The actual academic project remains the C Marksheet Generator. The C program should contain the core C implementation required by your teacher.

Open `index.html` in a browser to run the demo.
